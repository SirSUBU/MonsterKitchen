# Monster Kitchen

A single-player Unity 6 cooking game by Saubdiel Avalos (sa604). Serve vampires and tieflings the food they want: cooked for one, charred for the other.

Open this project in Unity **6000.6.5f1** and press Play. The cookbook opens first, including when the Kitchen scene is open in the Editor.
